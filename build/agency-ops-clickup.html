Agency Ops · ClickUp

At 5–20 accounts the failure mode isn't bad work — it's silent drift on one client while attention sits on another. This surfaces the drift, with the chase emails already written.

01 · The Problem

Why This Exists

Agency status reports measure the wrong thing. Tasks are closing, everything's green, and meanwhile one account hasn't seen a client-facing deliverable in five weeks.

Closing internal tasks while producing nothing the client can feel is the classic agency failure, so this skill will never mark an account green on throughput alone. Silence precedes churn — days since last contact is a first-class signal here.

It's also deliberately strict. A report where everything is green is a report nobody reads twice.

02 · Method

How It Works

01

Score every account on six signals

Throughput over 14 days, oldest untouched task, overdue vs no-due-date, unassigned work, days since last client-facing deliverable, days since last contact. Green, Amber, or Red — two breaches or 30 days without output is Red.

02

Find the capacity bottleneck

Open tasks, overdue count and tracked hours per person. Anyone carrying 30% above the team median is where the next missed deadline comes from. If one person blocks three Red accounts, that's structural, and the report says so.

03

Group stalled work by cause

Everything untouched over 21 days sorted into blocked-on-client, blocked-internally, scope creep, or genuinely forgotten. Most agency chaos is the first and third masquerading as a capacity problem.

04

Cap the actions at seven

Ranked, each with an owner and a day, opening with a single-sentence "the one thing". Chase emails for client-blocked items come pre-drafted — the report should reduce work, not create it.

03 · Run It

Two Minutes To First Output

# 1. Clone the repo
git clone https://github.com/seosdm/agency-ops-clickup.git

# 2. Connect ClickUp (or export tasks to CSV), then prompt:
Run the weekly agency-ops-clickup report.
Workspace: [name]. Week of [date].

# 3. Run it the same morning every week. The trend is the product.

No API keys, no setup. The skill is a SKILL.md file plus a worked example — it runs anywhere Claude does.
